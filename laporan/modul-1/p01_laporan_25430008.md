## 1. Tujuan Praktikum

Praktikum Modul 1 bertujuan untuk:

1. Mengenal lingkungan kerja basis data menggunakan MariaDB.
2. Memahami penggunaan XAMPP sebagai lingkungan server lokal.
3. Mengenal phpMyAdmin sebagai alat bantu pengelolaan database.
4. Membuat dan mengelola database menggunakan SQL.
5. Membuat user database.
6. Memberikan hak akses kepada user database.
7. Menguji hak akses user terhadap database.
8. Memahami pesan kesalahan ketika user tidak memiliki hak akses.

---

## 2. Dasar Teori

### 2.1 Basis Data

Basis data adalah kumpulan data yang disimpan secara terstruktur sehingga dapat dikelola, diakses, dan digunakan sesuai kebutuhan.

### 2.2 MariaDB

MariaDB merupakan sistem manajemen basis data relasional yang digunakan untuk menyimpan dan mengelola data. MariaDB menggunakan SQL untuk menjalankan perintah terhadap database.

### 2.3 XAMPP

XAMPP merupakan paket perangkat lunak yang menyediakan lingkungan server lokal. Salah satu komponen XAMPP yang digunakan dalam praktikum adalah MariaDB.

### 2.4 phpMyAdmin

phpMyAdmin adalah aplikasi berbasis web yang digunakan untuk mengelola database melalui antarmuka grafis. Dengan phpMyAdmin, pengguna dapat membuat database, tabel, user, serta mengatur hak akses.

### 2.5 User dan Hak Akses

User database merupakan akun yang digunakan untuk mengakses database. Setiap user dapat memiliki hak akses yang berbeda sesuai kebutuhan.

Beberapa hak akses yang umum digunakan antara lain:

* `SELECT` untuk membaca data.
* `INSERT` untuk menambahkan data.
* `UPDATE` untuk mengubah data.
* `DELETE` untuk menghapus data.
* `CREATE` untuk membuat objek database.
* `DROP` untuk menghapus objek database.

## 4. Langkah-Langkah Praktikum

### 4.1 Menjalankan XAMPP

XAMPP digunakan untuk menjalankan lingkungan server lokal dan layanan MariaDB.

Langkah yang dilakukan:

1. Membuka aplikasi XAMPP.
2. Menjalankan layanan database MariaDB.
3. Memastikan layanan dapat berjalan.
4. Membuka phpMyAdmin melalui browser.

Dokumentasi:

![Tampilan XAMPP](screenshot/01-xampp.png)

---

### 4.2 Mengakses MariaDB

MariaDB dapat diakses melalui Command Prompt atau terminal.

Perintah yang digunakan:

```sql
mysql -u root -p
```

Perintah tersebut digunakan untuk melakukan login ke MariaDB menggunakan user `root`.

---

### 4.3 Melihat Database

Untuk melihat database yang tersedia digunakan perintah:

```sql
SHOW DATABASES;
```

Perintah tersebut menampilkan daftar database yang terdapat pada server MariaDB.

---

### 4.4 Membuat Database

Database dapat dibuat menggunakan perintah:

```sql
CREATE DATABASE basisdata_25430008;
```

Setelah database dibuat, database dapat digunakan dengan perintah:

```sql
USE basisdata_25430008;
```

---

### 4.5 Membuat User

User database dapat dibuat menggunakan perintah:

```sql
CREATE USER 'user_25430008'@'localhost'
IDENTIFIED BY 'password';
```

User tersebut kemudian dapat diberikan hak akses sesuai kebutuhan.

> `password` pada contoh di atas merupakan contoh dan dapat disesuaikan dengan konfigurasi praktikum.

---

### 4.6 Memberikan Hak Akses

Hak akses dapat diberikan menggunakan perintah:

```sql
GRANT ALL PRIVILEGES
ON basisdata_25430008.*
TO 'user_25430008'@'localhost';
```

Perintah tersebut memberikan hak akses kepada user terhadap database `basisdata_25430008`.

Untuk melihat hak akses yang dimiliki user digunakan:

```sql
SHOW GRANTS FOR 'user_25430008'@'localhost';
```

---

### 4.7 Menguji Hak Akses

Setelah user dibuat dan diberikan hak akses, dilakukan pengujian untuk memastikan user dapat mengakses database sesuai hak yang diberikan.

Pengujian dilakukan dengan menjalankan perintah SQL dan mengamati hasil yang diberikan oleh MariaDB.

---

### 4.8 Menguji Akses yang Tidak Diizinkan

Apabila user tidak memiliki hak akses terhadap suatu database, MariaDB akan memberikan pesan kesalahan.

Contoh pesan kesalahan:

```text
ERROR 1044 (42000): Access denied for user
```

Kesalahan tersebut menunjukkan bahwa user tidak memiliki izin untuk mengakses database yang dituju.

## 6. Analisis

Berdasarkan praktikum yang dilakukan, database membutuhkan pengaturan user dan hak akses agar pengguna hanya dapat melakukan aktivitas sesuai dengan kewenangannya.

MariaDB menyediakan perintah SQL untuk membuat user dan memberikan hak akses. Perintah `GRANT` digunakan untuk memberikan hak akses, sedangkan `SHOW GRANTS` digunakan untuk melihat hak akses yang telah diberikan.

Pengaturan hak akses penting dalam keamanan database. Jika seorang user tidak memiliki izin terhadap database tertentu, sistem akan menolak akses tersebut dan memberikan pesan kesalahan.

Dengan demikian, penggunaan user dan hak akses dapat membantu menjaga keamanan serta membatasi penggunaan database.

## 7. Kesimpulan

Praktikum Modul 1 memberikan pemahaman mengenai lingkungan basis data menggunakan XAMPP, MariaDB, dan phpMyAdmin.

Database dapat dibuat dan dikelola menggunakan perintah SQL. Selain itu, user database dapat dibuat dan diberikan hak akses sesuai kebutuhan.

Penggunaan `GRANT` dan `SHOW GRANTS` membantu dalam mengatur serta memeriksa hak akses user. Pengujian akses juga menunjukkan bahwa MariaDB dapat menolak pengguna yang tidak memiliki izin.

Dengan demikian, pengelolaan user dan hak akses merupakan bagian penting dalam keamanan dan pengelolaan database.
